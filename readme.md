# Orbit — internship learning hub

A multi-page static frontend designed as a friendly Git practice project for internship students.

## Pages

- `index.html` — landing page
- `programs.html` — open internship roles with category filters
- `projects.html` — project showcase
- `resources.html` — learning library
- `profile.html` — sample student dashboard

## Run locally

This project has no packages to install. You only need [Node.js](https://nodejs.org/).

```bash
node server.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. Press `Ctrl + C` in the terminal to stop the server.

You can still open `index.html` directly in a browser or use a local-server extension.

## Suggested Git practice

1. Create a feature branch for a new role, resource, or project card.
2. Commit the HTML/CSS change with a focused commit message.
3. Open a pull request and request a review.
4. Resolve a planned conflict by editing the same resource entry on two branches.
